fdid – User Manual

Welcome

This book is the public tutorial for the fdid R package, which implements Factorial Difference-in-Differences (FDID) for panel data settings where all units experience a common event and differ in a baseline factor G (Xu, Zhao, and Ding 2026).

The tutorial is organized around the target the analyst wants to report. The binary and discrete-G workflow comes first. Continuous-G workflows then separate scalar slopes, level curves, derivative curves, observed-population average derivatives, fixed-reference contrasts, and support diagnostics.

Main user-facing functions:

  • fdid_prepare() reshapes long panel data into the wide format used by fdid().
  • fdid() estimates binary, discrete, kernel continuous-G, and DML continuous-G FDID models.
  • fdid_contrast() reports continuous-G level contrasts from stored curve objects.
  • fdid_derivative() reports fixed-G derivative values from stored curve objects.
  • summary() and plot() display fitted objects.

Organization

  • Chapter 1  Get Started covers installation, loading, and the required data shape.
  • Chapter 2  Binary G covers the original binary/discrete-G workflow.
  • Chapter 3  Continuous-G Overview maps user targets to continuous-G methods, support checks, and reporting views.
  • Chapter 4  Kernel Estimator for Continuous G covers kernel level and derivative curves.
  • Chapter 5  DML Estimators for Continuous G covers DML scalar, flexible-curve, and incremental targets.
  • Chapter 6  Visualization Options documents current base-graphics plotting.
  • Chapter 7  Reporting And Inference centralizes summaries, contrasts, derivatives, and interval labels.
  • Chapter 8  Sensitivity Analysis gives applied sensitivity checks.
